GitHub Copilotのパーソナルカスタム指示を追加する方法

GitHub Copilotのパーソナルカスタム指示（Personal Custom Instructions）機能を使用すると、Copilotの応答をあなたの好みやプロジェクトの要件に合わせてカスタマイズできます。この機能により、コーディングスタイル、命名規則、使用するフレームワークなどの好みをCopilotに伝えることができます。

1. GitHub Copilot設定にアクセスする

Visual Studio Codeの場合：
① Visual Studio Codeを開きます
② 画面右下のステータスバーにあるGitHub Copilotアイコン（または左下の歯車アイコン）をクリックします
③ 「Edit Instructions」または「Copilot設定を編集」を選択します

GitHub.comの場合：
① https://github.com/settings/copilot にアクセスします
② 右上のプロフィール画像をクリック
③ 「Settings」を選択
④ サイドバーの「Copilot」をクリック
2. カスタム指示を追加する

「Custom Instructions」または「カスタム指示」のセクションを見つけます。ここに、あなたのコーディング規約や好みを記述できます。

記述例： 
私のコーディング規約：
- Javaのメソッド名はキャメルケース（camelCase）を使用する
- クラス名はパスカルケース（PascalCase）を使用する
- インデントはスペース4つを使用
- コメントは日本語で記述する
- エラーハンドリングは必ず実装する
- 変数名は意味のある名前を使用し、略語は避ける

プロジェクト情報：
- Java 17を使用
- Spring Bootフレームワークを使用
- Lombokを使用してボイラープレートコードを削減
- RESTful APIの開発

3. 設定を保存する

カスタム指示を入力したら、「Save」または「保存」ボタンをクリックして設定を保存します。

4. カスタム指示の動作確認

設定を保存した後、GitHub Copilotは自動的にあなたのカスタム指示を考慮して提案を生成するようになります。

コードエディタで新しいコードを書き始めると、Copilotがあなたの指示に従った提案を行うことを確認できます。

重要な注意事項

・利用可能性： この機能は、GitHub Copilot Individual、Business、またはEnterpriseプランで利用可能です。GitHub Education（学生・教員アカウント）でも利用できる場合があります。

・更新頻度： カスタム指示はいつでも更新できます。変更は即座に反映されます。

・機能の場所： この機能は2023年後半から順次展開されており、お使いの環境によってはまだ利用できない場合があります。その場合は、GitHub CopilotやVS Codeのバージョンを最新にアップデートしてください。

・代替方法： カスタム指示機能が利用できない場合は、コードコメントで指示を書くことで同様の効果を得ることができます。例：
// コーディング規約: メソッド名はキャメルケース、インデントは4スペース

よくある質問

Q1: カスタム指示が見つかりません。どこにありますか？
A1: GitHub Copilotの設定場所は、使用しているツールによって異なります：
　・VS Code: 右下のCopilotアイコン → 「Edit Instructions」
　・GitHub.com: Settings → Copilot → Custom Instructions
　・JetBrains IDE: Settings/Preferences → Tools → GitHub Copilot

Q2: カスタム指示はプロジェクトごとに設定できますか？
A2: 2024年1月現在、カスタム指示はアカウント全体に適用されます。プロジェクト固有の指示を行いたい場合は、プロジェクトのルートに.github/copilot-instructions.mdファイルを作成する方法もあります（この機能は試験的なものです）。

Q3: カスタム指示の文字数制限はありますか？
A3: 通常、数千文字までの指示を記述できますが、あまり長すぎると効果が薄れる可能性があります。簡潔で明確な指示を心がけましょう。

Q4: カスタム指示はGitHub Copilot Chatにも適用されますか？
A4: はい、カスタム指示はGitHub Copilotのコード補完とCopilot Chat（チャット機能）の両方に適用されます。
