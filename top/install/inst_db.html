データベースの生成
PowerCampusが使用するデータベースを作成します．PostgresqlのpgAdmonⅢというツールを使います．pgAdmonⅢは、データベースに関するあらゆることをGUIで操作できる便利なツールです．


pgAdminⅢの起動

スタート⇒全てのプログラム⇒PostgreSQL8.0⇒pgAdminⅢ と選択して起動します．
よく使うので、アイコンをデスクトップに貼り付けておくといいでしょう．


Postgresql にログインする

　図の赤丸の部分をダブルクリックして、ログインダイアログを開きます．
スーパーユーザーのパスワードを入力してください．





データベース作成

ログインすると右図のように表示されるので、「データベース」をマウスの右ボタンでクリックし、さらに、「あたらしいデータベース」を選択します．




　データベース作成ダイアログが表示されます．ここでは、図に示したの同じものを記入してください．データベース名はPowerCampusのインストール時に設定していた

　　PowerCampus

です．P と C は大文字で入力してください．

後の入力は以下の通りです．

　オーナー　　　　： postgres
　エンコーディング： EUC_JP

　以上３項目だけ記入して、OKをクリックするとデータベースが作成されます．





データベーステーブルの作成

マウスでデータベース名 PowerCampus をクリックして青く反転させます．すると、上段のツールバーのボタンが使えるようになります．



ツールバーの中から、SQLボタンを選んでクリックします．



SQL画面が開くので、図中の赤丸の部分にあるファイルを開くボタンをクリックします．するとファイルダイアログが表示されます．



開くファイルは、tomcat インストールディレクトリ(Tomcat)の中にある create.sql です．

　 C:\Tomcat\webapps\pc\system\sql\create.sql

です．ファイルダイアログでこれを指定して開いてください．





create.sql には、必要なデータベーステーブルを作成するためのSQLスクリプトが入っています．右図のように、実行ボタンをクリックして、スクリプトを実行してください．



成功すると右図のように表示されますので、ウィンドウを閉じます．


確認

データベースのツリーを右図のようにたどり、１５個のテーブルが作成されたことを確認してください．出来ていれば、pgAdminⅢを閉じます．



★参考
　あとで、実際にデータが入力されてからですが、この画面を開き、右側のテーブル名をクリックしからツールバーのめがねのボタンをクリックすると、該当のデータベーステーブルの内容を一覧し、変更や削除が簡単にできます．
