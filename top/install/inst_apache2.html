Apacheのインストール
　ウェブサーバーのapache 2.0.54 をインストールします．apacheは世界で最も普及しているフリーのウェブサーバーです．WindowsではIISを使うケースもありますが、microsoftの他のシステムと連携する必要がないのであれば、IISを使う理由は全くありません．
　インストールはきわめて容易です．ただ、インストール場所を標準の場所にしないということに気をつけましょう．それ以外では、特に注意することはありません．おおむね、next ボタンをクリックするだけです．


インストールの開始

　をダブルクリックしてインストールを開始します．最初の画面ではnextをクリックします．

　

使用許諾

　apacheのライセンス規定に同意してnextをクリックします．




説明表示

　apache の説明が表示されます．これも next をクリックします．



情報の入力

　ドメイン名、サーバー名、(あなたの)メールアドレスを入力します．

(1) 大学の学内にサーバーを設置する場合
　ドメイン名とサーバー名は、大学の管理者から指定があるはずですから、それに従ってください．メールアドレスは、サーバー管理者のメールアドレスですから、あなたのメールアドレスになります．

　《例示》
　　ドメイン名：　　 college.ac.jp
　　サーバー名：　　 www3.college.ac.jp
　　メールアドレス:　myname@college.ac.jp


(2) 自宅サーバーの場合
　ドメイン名もサーバー名も、共に、取得したドメイン名を書きます．自宅サーバーの場合は、まず自分のドメイン名を取得しなくてはなりません．その方法など詳細は、「PowerCampus desktop に必要なコンピュータ環境」(net.html) を参照してください．メールアドレスはもちろんあなたのメールアドレスです．

　《例示》
　　ドメイン名：　　 mydomain.com
　　サーバー名：　　 mydomain.com
　　メールアドレス:　myname@college.ac.jp


セットアップの方法を選択

　自分で詳細を指定するかどうかですが、規定値のままで差し支えありませんので、そのまま next をクリックします．




導入先ディレクトリの指定

　apacheをどこにインストールするか指定します．そのまま next をクリックすると Cドライブの "Program Files" ディレクトリになりますが、ディレクトリ名に空白が含まれていると、使用にあたって引用符で囲まねばならないなどの制限が出てきます．また、あとで環境変数を作成しますが、その時も、規定値のような長い名前では間違いの元になります．

　なお、PowerCampusはapacheのホームディレクトリを使いませんが、規定値のままだとインストール先にホームディレクトリができてしまいます(設定ファイルを書き直せば別の場所に移せます)．ホームページなども作成する予定ならば、容量のあるドライブを指定してそちらへインストールした方がいいでしょう．





　ここでは、

　　　　　　 C:\Apache2

にインストールします．
　そこで、 Change をクリックしてディレクトリ選択画面へ移り、c:\ を選択します．下段の入力欄は C:\ のままにして OK ボタンをクリックします．Apache2 というフォルダ名は、インストーラーが自動的に付けてくれます．






　apache を導入するディレクトリが c:\ となっていることを確かめてから、next をクリックしてください．



インストール準備完了の告知

　準備ができたことが知らされています．install をクリックしてインストールを開始してください．



インストール実行中

　自動でインストールが進行します．




完了

　完了が表示されますので、Finishをクリックして終了します
