PowerCampusの起動方法
　PowerCampusを起動するには、tomcat と apache 及び postgresql がすでに起動していることが必要です．ただ、これらは、Windowsのサービス管理に組み込まれていますので、パソコンを起動すると、自動的にこれらも起動されています．したがって通常は、ブラウザを開いて、

　　http://《サーバー名》/PowerCampus/pc/top/index2.html

をアクセスするだけです．
また、学生用は

　　http://《サーバー名》/PowerCampus/pc/top/

です．


【起動サービスの管理】

　パソコンは使うがサーバーは止めておきたいという時は、tomcat と apache 及び postgresql を停止します．これには、Windowsのサービス管理を使います．そこで、以下では、まずサービス管理のアイコンをデスクトップに貼り付ける方法を説明します．

　次に、Tomcat の再起動をサービス管理を使って行います．これは、Tomcatにapacheのための情報ファイルを作成させるため、インストール直後に必要な処理です．これをやっておくのは、パソコンを再起動したとき、もしも先にapacheが起動してしまうと、この情報ファイルがないので、Tomcatとの連携がうまくいかず、PowerCampusを起動できなくなるからです．

　そして最後に、tomcat と apache 及び postgresqlのサービスを自動起動から手動起動に切り替える方法も説明します．

★パソコン下段のタスクバーに が表示されていると思いますが、これはapache と Tomcat の起動状態を見たり、実際に起動や停止を行ったりするアイコンです．Windowsのサービス管理を使うので、これを操作する必要はありません．
