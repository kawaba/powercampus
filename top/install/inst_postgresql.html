postgresql-8.0.3のインストール
　postgresql は、これまでUNIXやLINUXの世界で使われていたリレーショナルデータベースシステム(RDBMS)です．商用や営利利用も可能なフリーのソフトウェアですが、MS-SQLやOracleと並立する高機能なシステムです．バージョン8.0からWindows版が配布されるようになり、そのおかげでPowerCampusのWindows版が可能になりました．データベースシステムは、規模が大きくなるほど性能の違いが出てくるのですが、Postgresqlは安心して大規模システムに適用できる数少ないDBMSのひとつです．

　インストールも非常に容易です．以下の解説の沿って実行してください．


★最初に以下のように、ダウンロードした postgresql-8.0.3-ja.zip をダブルクリックして解凍しておきます(①)．ダブルクリックすると、postgresql-8.0.3-ja というフォルダが作成され、その内容が表示されます．
　　解凍したファイルの中の、postgresql-8.0.3-ja.msi をダブルクリック(②)するとインストールを開始します．






開始
　
　最初の開始画面では、次へをクリックします．


説明
　
　Postgresql データベースについての説明です．分かる範囲で目を通しておくといいでしょう．


インストール先の選択

Postgresql をどこへインストールするか指定します．インストール先にデータベース本体も出来てしまいますから、十分に容量のあるドライブ装置を選んで、その装置の postgres というフォルダーにインストールしてください．ここでは、D:\postgres にインストールしています．

　Browse ボタンをクリックします．




　指定場所に Dドライブを選択し、下段のフォルダ名に postgres と入力し、OKをクリックします．




　元の画面にもどったら、インストール先として d:\postgres\ が指定されていることを確認してから、次へをクリックします．




サービスとして起動するよう指定する

　サービスとは、WindowsによるPostgresqlの自動起動サービスです．これにより、パソコンの電源を入れるたびにPostgresqlを手動で起動する必要がなくなります．

　PowerCampusのインストール指定を簡単にするため、ここでは、画面の表示に一切手を加えないで下さい．そのままOKボタンをクリックします．

　下図のように、３つの画面が次々と表示されますので、「はい」と「OK」をクリックしてください．



データベース生成と管理者の設定

　ポート番号とアドレスは変更しません．赤枠で囲った部分を好きに変えると、PowerCampusのインストールで間違いの原因になります．赤で指定した通りに設定してください．

　　ローケル　　　　：　C
　　エンコーディング：　EUC_JP
　　スパーユーザー名：　postgres

また、パスワードも、PowerCampusのインストールに必要なデータです．どこかにメモを取るなどして、忘れないように注意してください．
　
　また、pgadmin という管理ツールでデータベースを操作する時にも、ここで指定したスーパーユーザー名(postgres)とパスワードが必要になります．


その他の設定

　これ以降は、特に設定しません．次へをクリックします．



　ここも次へをクリックします．



インストール開始

　準備ができたという表示ですから、次へをクリックしてインストールを開始します．



　インストールは完了まで暫く時間がかかります．



完了

　終わるをクリックします．

　なお、PowerCampusのために、データベーステーブルを作成しますが、それはPowerCampusをインストールした後、Postgresql の管理プログラム(pgadmin)で行いますので、Postgresql のインストールはこれで完了です．
