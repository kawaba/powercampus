Java(J2sdk5.0)とTomcat()のインストール

　１．Javaのインストール
　２．Tomcatのインストール

　PowerCampusはjava言語でかかれていますが、独自開発したJEF(Java Easy Framework)により作成していますので、Java言語を処理するためのJ2sdkという基本セットと、Tomcatをインストールするだけで済みます．Tomcatはapacheと連携してウェブベースのサーバープログラムを実行します．



１．Javaのインストール

　最新のバージョン5.0をインストールします．すでに他のバージョンのjavaをインストールしている方は、それをアンインストールしてから、この処理を行ってください．古い版では、Tomcatとの関係から、不具合が起こる可能性があります．

　実際には、javaの実行環境(jre)のみをインストールしてもPowerCampusの稼動には問題ありませんが、サポートの都合から、開発環境を含むJ2sdkをインストールします．したがって、インストーラは最初にJ2sdkをインストールし、次に、jre をインストールします．２度インストール作業を実行するので、導入先なども２度指定することになります．このことを念頭において、以下の説明を見てください．


インストーラーの起動

　をダブルクリックして、インストーラーを起動します．圧縮ファイルにもかかわらず、50MBもありますので起動にはしばらく時間がかかりますが、やがて右のような使用許諾画面が表示されます．

同意するにチェックを入れて、次へをクリックします．




インストール先の指定

　標準では、Cドライブの Program Files ディレクトリへ導入されますが、ディレクトリ名に空白が含まれていると、使用にあたって引用符で囲まねばならないなどの制限が出てきて好ましくないので、ここでは、Cドライブの java というフォルダにインストールします．

　　C:\java

特別の事情がないかぎり、このようにされることをお勧めします．

変更をクリックします．



　インストール場所にCドライブを指定してから、下段のフォルダ名欄に c:\java と記入しOKをクリックします．



　元の画面に戻りますので、インストール先に c:\java\ と記入されていることを確認の上、次へをクリックします．



j2sdkの自動インストール

　j2sdk がインストールされます．数分程度の時間がかかります．


jreのインストール先の指定

　ここからは、JRE(Java2 Runtime Environment)のインストールです．インストール先は j2sdk と同様にCドライブの jre ディレクトリに変更します．

変更をクリックします．



　インストール場所にCドライブを指定してから、下段のフォルダ名欄に c:\jre と記入しOKをクリックします．




　元の画面に戻りますので、インストール先に c:\jre\ と記入されていることを確認の上、次へをクリックします．


使用するブラウザの確認

　使用するブラウザを聞いてきます．PowerCampusが対応しているのは、Internet Explorerです．他のブラウザでは画面が乱れる可能性があります.


jre の自動インストール

　JREがインストールされます．数分かかります．



完了

　完了表示です．完了をクリックして終了します．





２．Tomcatのインストール
　
　Tomcat はウェブ上で発行されるサーバープログラムへの要求を受け取って、それをjavaのプログラム本体に受け渡し、処理後に、結果の出力を行うためのシステムです．サーバープログラムはjavaサーブレットとよばれることから、Tomcatをサーブレットコンテナと呼ぶことがあります．
　ウェブサーバーであるapacheは、通常のブラウジング要求は自ら対応し、サーバープログラムの呼び出し要求はそれをTomcatに投げて処理させます．ですから、apacheとTomcatは密接に連携しており、両方のパージョンも適合するか否かがクリティカルに決まっています．

　PowerCampusでは、Tomcat5.5.9とApache 2.0.54 を使います．Apacheの場合と同じく、すでにTomcatの古いバージョンをお使いの方は、5.5以上のバージョンに入れ替える必要があります．バージョンを揃えない場合、PowerCampusは稼動しませんのでご注意ください．


インストーラーの起動

　をダブルクリックして、インストーラーを起動します．



使用許諾

使用許諾画面です．I Agree をクリックして次へ進みます．


インストールパッケージの選択

全てのパッケージをインストールするよう、Full を選択して next をクリックします．


インストール先の選択

これも、標準のインストール先ではなく、Cドライブの Tomcat フォルダにインストールします．

　　C:\Tomcat

特別の事情がないかぎり、このフォルダ名にされることをお勧めします．

Browse をクリックしてください．





ファイルダイアログが開くので、マイコンピュータからローカルディスク(C)を選択し、OKをクリックします．





下段のインストール先(Destination Folder)には自動的に C:\Tomcat 5.5 という表示が入りますので、これを

　　　C:\Tomcat

と変更します．

確認のしたら Next をクリックします．



admin パスワードの設定

　これは、tomcat付属の管理ツールにログインするためのものです．PowerCampusではこのパスワードは使いませんが、一応、何か設定しておいてください．



JRE の所在の確認

JRE(Java Runtime Environment)の所在を確認するダイアログです．検索して自動的に表示さるはずですから、よければ Install をクリックします．



インストール実行

インストールが始まります．



インストールの終了が報告されます．tomcatを起動するという上段のチェックボックスをクリアしてから、Finish をクリックしてください．
